# TechRepair — Manual do Utilizador

## Como Iniciar a Aplicação

1. Verificar se o .NET SDK está instalado:
   ```
   dotnet --version
   ```

2. Abrir o projeto no Visual Studio Code ou através do terminal.

3. Restaurar as dependências:
   ```
   dotnet restore
   ```

4. Compilar a aplicação:
   ```
   dotnet build
   ```

5. Executar a aplicação:
   ```
   dotnet run
   ```

6. Aceder ao navegador em `https://localhost:5001` ou `http://localhost:5000`.
